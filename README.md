# Light Barrier Synchronous

This is a robust continuous wave modulated light barrier with a synchronous detector. The sensitivity is very low against other modulated ligth sources. All electrical interfaces are protected against reverse polarity, over voltage and over current.

It contains only easily available discrete standard components and the board has only one solder side.

## Technical Data

| Parameter              | Min | Typ | Max | Unit |
| ---------------------- | --- | --- | --- | ---- |
| Operating Voltage      | 3.3 | 5   |  35 |    V |
